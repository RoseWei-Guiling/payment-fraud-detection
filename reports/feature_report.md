# Feature report

Generated by `scripts/build_features.py`. Information value (IV) is measured on training months only.

**285 features** for 590,540 transactions.

## Feature groups

| Group | Features | What it captures |
| --- | --- | --- |
| base | 96 | Named transaction fields: amount (plus log, cents, round-amount flag), time, product, card, address, email domain, C/D/M families, identity fields |
| missingness | 5 | How many V / D / M / identity fields are missing, and how many M match flags are true |
| email | 5 | Email provider and suffix, purchaser vs recipient domain match |
| device | 3 | Device, operating system and browser family (coarse groups) |
| d_normalised | 4 | day - D for D4, D10, D11, D15: turns 'days since' into stable start dates |
| frequency | 8 | How common the card, address, email, device or fingerprint is (training months) |
| target_encoding | 5 | Smoothed fraud rate for email domains, card type x product, device family, address (out-of-fold on training rows, training-fitted for later months) |
| customer_history | 5 | Customer's average of C1, C13, C14, D15, dist1 over EARLIER transactions |
| device_sharing | 2 | Customers per device fingerprint (training months); fingerprint new for this customer |
| vesta_v_reduced | 142 | Vesta-engineered V columns after removing near-duplicates |
| velocity | 10 | Step 2 SQL features: transaction counts and spend in the last 1h / 24h / 7d, gaps, newness |
