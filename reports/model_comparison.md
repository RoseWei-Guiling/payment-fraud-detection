# Challenger models vs the rules champion

Generated by `scripts/train_models.py`. Trained on training months, compared on the validation month.

Every model blocks the same **4.3%** of payments as the rules champion, so the question is simply: blocking the same number of customers, who catches more fraud?

- **AUC / Gini / PR-AUC**: how well the score ranks fraud above genuine payments over every cut-off (Gini 0 = random, 1 = perfect; PR-AUC focuses on the rare fraud class).
- **decline_rate_to_match_champion**: how many payments the model must block to catch as much fraud as the champion. Lower is better.
